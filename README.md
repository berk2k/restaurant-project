# 🍽️ Digital Restaurant Ordering System
Dockerized 🚢 digital restaurant ordering system with QR code access 📱✨.
---
# 🚀 Features
🔥 Fully containerized with Docker for easy deployment

📱 Customers order via QR codes on their tables

⚙️ CI/CD pipeline runs unit tests ✅, pushes Docker images to Docker Hub 🐳, and deploys automatically to the cloud ☁️

🛠️ Easy to maintain and scale

---
# 🛠️ Tech Stack
Docker

CI/CD (GitHub Actions)

Cloud Deployment

.Net Core

MSSQL

---

# 📦 Deployment Pipeline
💡 Code pushed →

🧪 Unit tests run →

🐳 Docker image built & pushed to Docker Hub →

☁️ Deployed to cloud automatically
